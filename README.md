# E-Commerce Customer Analytics & Revenue Intelligence Platform

## Project Overview

An end-to-end data analytics project focused on analyzing e-commerce
sales, customer behavior, product performance, and operational metrics.

The project uses Python, SQL, PostgreSQL, Excel, and Power BI to transform
raw e-commerce data into actionable business insights.

## Business Objectives

- Analyze revenue and sales trends
- Understand customer purchasing behavior
- Identify high-value customers
- Perform RFM customer segmentation
- Analyze customer retention using cohort analysis
- Identify high-performing products and categories
- Analyze delivery and operational performance
- Build interactive Power BI dashboards
- Generate data-driven business recommendations

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains information related to:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation
